# 按鈕壓扁、移除說明文字

| 項目 | 內容 |
|---|---|
| 原因 | 使用者在 iPhone 測試後要求：不要出現多餘的解釋；按鈕更扁平，把空間讓給內容；以模擬器 iPhone 17、iPhone 17 Pro Max 調整 |
| 分支 | `feat/flat-ui` |
| 日期 | 2026-11-29 |

## 內容

| 項目 | 說明 |
|---|---|
| 控制項高度 | 按鈕、輸入欄、選單外觀 44px → 36px（`--control`）；圓角 10px → 8px |
| 觸控範圍 | 按鈕與連結按鈕以 `::after` 上下延伸到 44px（`--hit`，Apple HIG）；方形按鈕（拖曳把手、上移下移）四邊都延伸；分頁列維持 44px |
| 清單列 | 48px、52px 的列改為 44px |
| iOS 表單 | 日期與時間欄位文字垂直置中；`select` 設固定高度（iOS 不套用 min-height） |
| 說明文字 | 移除 22 個檔案中解釋功能運作的段落；保留狀態、空清單與不能操作的原因（例如「確認旅行基線後可以在這裡修改日期。」） |

| typecheck、lint | 通過 |
