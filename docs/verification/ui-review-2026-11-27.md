## 問題

| 編號 | 問題 | 證據 |
|---|---|---|
| U-1 | 深色模式對比不足：系統為深色時，頁面背景仍是白色，但 T39–T41 頁面把次要文字改成淺灰 `#9198a1`，對比只有 2.91:1（WCAG AA 要求 4.5:1） | `ui-review-timeline-dark-390.png`；量測 `muted = rgb(145,152,161)`、`body 背景 = 透明` |
| U-2 | 其餘 10 個 CSS 沒有深色模式；同一個 App 在深色系統下有的頁面變色、有的不變 | 靜態統計 |
| U-3 | 沒有設計 token：18 個顏色、11 個字級寫死在 13 個檔案，改風格要逐檔修改 | 靜態統計 |
| U-4 | 沒有導覽：當日行程頁以三組「連結＋說明」列出 Incident Mode、行程記憶、Actual Timeline；其他頁面沒有回到行程的路徑 | `ui-review-today-light-390.png` |
| U-5 | 觸控目標 40px，旅行當天單手操作偏小 | 量測 |
| U-6 | 戶外可讀性：主要內容文字 14–16px，次要文字 12.8px（0.8rem），陽光下偏小 | 靜態統計 |
| U-7 | 首頁沒有字型與背景，看起來像未完成的頁面 | `ui-review-home-light-1280.png` |

U-1 是錯誤，不論選哪個方向都要修。

## ORYZO 的要素與限制

| 要素 | ORYZO | 套用到本 App 的問題 |
|---|---|---|
| 底色 | 暖黑 `#100904`，表面 `#382416` | 深色模式可直接用；淺色模式要自行推導 |
| 文字 | 米白 `#ffedd7`（對 `#100904` 17.3:1） | 可用 |
| 次要色 | `#6c5f51`（對底色 3.19:1） | 不足 4.5:1，不能用於文字，只能用於分隔線 |
| 點綴 | 橘 `#dc5000`（對底色 4.88:1），只用於短字與連結，不用於按鈕 | 淺色底上只有 3.53:1，淺色模式要改深一階（`#b34100`，5.0:1） |
| 字型 | 全大寫、字重 500，正文 29px 字重 400 | 中文沒有大小寫；29px 正文不適合資訊密集的手機頁面 |
| 形狀 | 膠囊按鈕（圓角 36px）、卡片 12px、細虛線分隔、無陰影 | 可直接用 |
| 版面 | 每段一整個畫面高、大量留白 | 旅行當天需要一眼看到時間與下一站，不適合 |

中文轉換：英文標籤（MORNING CHECK、DAY READY、AT RISK）用全大寫、字重 500、字距 0.04em；中文標題以字重 500 與較大字級表現，不加字距。

## 方向

| | A：ORYZO 工作版（推薦） | B：ORYZO 展示版 | C：只換色 |
|---|---|---|---|
| 做法 | 深色忠實套用 ORYZO 色彩、膠囊按鈕、虛線分隔；淺色以暖紙色 `#fbf3e8` 為底、暖黑字；保留資訊密度 | 照 ORYZO 的大字與留白：標題 32–40px、正文 18–20px，每段獨立區塊、12px 卡片 | 只建立 token、修深色錯誤、換成 ORYZO 色彩，版面與字級不動 |
| 字級 | 正文 17px、次要 15px、標題 20–28px（4 級） | 正文 19px、標題 32–40px（5 級） | 維持 11 級 |
| 按鈕 | 44px 高膠囊；每段最多一個實心按鈕（`#382416`） | 52px 高膠囊 | 44px 高，維持方角 |
| 導覽 | 行程內加一排膠囊分頁：今天、每日、候選、提案、記憶、旅後 | 同 A | 不加 |
| 點綴橘 | 只用於 At Risk、衝突、晚到等短字 | 同 A | 同 A |
| 當日行程（390）長度（依字級與間距估計） | 約為現在的 1.1 倍 | 約 1.8 倍 | 約 1 倍 |
| 工作量 | 1 個全域 token 檔＋13 個 CSS 改寫＋導覽元件 | A 再加每頁重排 | 1 個 token 檔＋13 個 CSS 換色 |
| 風險 | 低 | 現場要捲動找下一站；資訊頁變長 | 換色後仍是現在的工程介面感，ORYZO 只剩顏色 |

推薦 A：旅行當天在戶外單手看手機，需要一眼看到時間、下一站與按鈕；A 保留密度，同時拿到 ORYZO 的色彩、膠囊與虛線語言，並修好深色錯誤與觸控尺寸。

## 不採用

依全域守則，任何方向都不使用：hero 加三張相同的 feature card、「看更多 →」、` · ` 分隔的 meta 字串、連結後的箭嘴、色塊圖例、漸變、霓虹、粒子、逗號式口號。
