## 設計

| 項目 | 內容 |
|---|---|
| 正式資料寫入 | 基線、項目、每日、移動段、版本不授予 authenticated 寫入權，只由 `applyChange`（T09）寫入（S-01） |
| AI 提案 | 成員只能以本人名義建立 `pending` 提案；AI 提案（`proposer_role` 不為空）由伺服器函式建立 |
| 欄位級權限 | 通知只授予 `read_at` 更新；唯讀連結只授予 `revoked_at` 更新 |
| Notifier | 寫入他人通知須以伺服器權限執行（T09 決定執行方式）；成員的 client 沒有 notifications 的 insert 權限 |
| 依賴檢查 | M-01 規則排除 `*.test.ts`，測試檔可 import vitest |
