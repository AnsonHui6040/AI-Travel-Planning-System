## 設計

| 項目 | 說明 |
|---|---|
| 依據 | Google 官方文件（2026-11-23 讀取）：Text Search (New)、Place Details (New)、Place Photos (New)、Maps URLs、Places API 政策 |
| place_id 解析（S-16） | `resolvePlaceId`：POST `places:searchText`，欄位遮罩 `places.id,places.displayName,places.location`，有參考位置時以 5 公里圓形偏向。名稱以 NFKC、忽略大小寫、空白與標點後互相包含才算相符；有參考位置時需在 5 公里內。結果只有 place_id 或未解析原因（找不到、名稱不符、距離太遠） |
| 座標（D28） | `coordinates`：欄位遮罩只有 `location`。`coordinatesDue` 列出取得超過 30 日或尚未取得的項目；資料庫每日清除逾期座標 |
| 詳情與照片（D14） | `liveDetails` 回傳名稱、地址、評分、Google Maps 連結與照片名稱及作者標示，型別標示不可儲存，只供即時顯示。`photoUri` 以 `skipHttpRedirect=true` 換成不含 key 的 https 圖片網址；照片名稱會過期，不快取。顯示時必須列出作者標示與「Google Maps」來源，於行程 Card 畫面（T29）實作 |
| 導航（D26） | `directionsUrl`：`https://www.google.com/maps/dir/?api=1&destination=…&destination_place_id=…&travelmode=transit`，不需要 key |
| key | Places API 請求以 `X-Goog-Api-Key` 標頭傳送；照片 media 端點依官方文件以查詢參數傳送，只在伺服器執行，回傳的圖片網址不含 key。錯誤訊息固定，不含 key 或回應內容 |
| key 測試呼叫（C-03） | Text Search，欄位遮罩只有 `places.id`（Essentials ID Only，最低費用），`pageSize: 1`。註冊到 `apps/web/lib/server/api-keys.ts` 的 `keyTesters` |
| 連線 | 只連 `places.googleapis.com`（https），10 秒逾時，拒絕 redirect；限流時回報錯誤，不自動重試 |
| 輸入檢查 | place_id 與照片名稱先比對格式，不合格不送出請求，避免組出其他路徑 |

## 安全審查（S-15）

| 檢查 | 結果 |
|---|---|
| key | 只在伺服器使用；不出現在回傳值、錯誤訊息、導航連結或 client bundle |
| 請求偽造 | place_id 與照片名稱以格式白名單檢查後才組成網址；固定主機與 https；拒絕 redirect |
| 回應 | 只取需要的欄位並檢查型別；Google Maps 連結、作者連結與圖片網址只接受 https |
| 保存 | 資料庫限制座標必須對應 place_id 與取得時間，逾 30 日清除；名稱、地址、評分、照片不寫入 |
| 權限 | 清除函式只限排程（postgres）執行，`authenticated` 呼叫被拒 |
