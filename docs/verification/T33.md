## 權限表（唯讀連結欄）

| 動作 | 唯讀連結 | 測試 |
|---|---|---|
| 檢視行程 | 可（只有已排入的行程） | `22_readonly_links.test.sql`、E2E |
| 檢視他人敏感欄位 | 依當事人開關（「提供給 Viewer 與唯讀連結」） | `22_readonly_links.test.sql`、E2E |
| 觸發 AI、批准、提出或否決提案、編輯基線、上傳照片、記錄完成 | 不可 | 唯讀頁面沒有任何操作（E2E）；`readonly_trip` 是唯一可呼叫的函式，只回傳資料；`readonly-boundary.test.ts` |
| 檢視 Change Log | 不可 | `readonly_trip` 不回傳版本與提案 |
| 其他（轉移、退出、邀請、唯讀連結、刪除） | 不可 | 未登入只能執行 `readonly_trip`；建立唯讀連結只授權 authenticated 並限 Owner（pgTAP） |

## 設計

| 項目 | 說明 |
|---|---|
| 建立與撤銷 | `create_readonly_link(p_trip, p_days)`：只限 Owner，期限 1–30 天（畫面提供 7 天與 30 天），每個行程最多 10 個有效連結；`revoke_readonly_link`。收回 authenticated 對 `readonly_links` 的 INSERT，token 只能由資料庫產生 |
| 讀取 | `readonly_trip(token)`：anon 可呼叫，只回傳行程名稱與日期、每日狀態、已排入行程的項目（不含 place_id 與座標，D28），以及開啟「提供給 Viewer 與唯讀連結」的敏感欄位；其他情況回傳 null，不說明原因 |
| 頁面 | `/r/<token>`：不必登入；不顯示照片（照片與地點資料需成員權限或付費 API）；`referrer: no-referrer`、`noindex` |
| Owner 畫面 | 成員頁新增「唯讀連結」：建立後只顯示一次連結，列出狀態與到期時間，可撤銷 |

## 安全審查（S-15）

| 檢查 | 結果 |
|---|---|
| token | 256 位元、只存雜湊、只顯示一次、可撤銷、會到期；Owner 不能指定弱 token |
| 資料範圍 | pgTAP 確認只回傳已排入行程的項目（候選不回傳）、不含 place_id 與座標、只有開放的敏感欄位；提案、版本、成員名單、照片不在函式回傳的結構內 |
| 權限 | `readonly_trip` 擁有者只有 SELECT；anon 只能執行這一個函式；其他函式未授權 anon |
| 觸發 AI 或付費 API | 頁面沒有操作；依賴範圍測試與 E2E 網路檢查 |
| 外流 | 連結頁 `no-referrer`、`noindex` |

沒有發現可被利用的漏洞。
