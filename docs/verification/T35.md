## 設計

| 項目 | 說明 |
|---|---|
| 當日包 | `@atps/offline` 的 `buildDayPack`（純函式）：當天已排入的項目、最遲離開時間（下一站開始扣掉交通；下一站是固定活動時另扣 15 分鐘緩衝；沒有估算以 30 分鐘計）、固定活動、Backup、照片（只保留站內 `/api/photos/` 網址）、行程版本 |
| 倒數 | `leaveCountdown` 以目的地時區計算；`isPackDay` 只在當天顯示倒數，每分鐘更新 |
| 儲存 | 線上開啟 `/trips/<行程>/today` 時存入 IndexedDB（每個行程最新一份），並預先載入離線頁面與照片 |
| service worker | `/trips/<行程>/today` 先連網，離線時改回應 `/offline-today`（從 IndexedDB 讀取）；`/_next/static`、`/api/photos`、`/icons` 先用快取；API、Server Action 與其他頁面不快取 |
| 修改佇列（SH-05） | 修改先排入 IndexedDB 佇列（同一項目只保留最新），保留排入時的行程版本；有網路或恢復網路時依序送出；網路失敗停止並保留其餘，伺服器拒絕的修改移除並告知 |
| 同步端點 | `/api/trips/[tripId]/offline-proposals`：Origin、登入、速率限制（C-11）；只限 Owner、Companion；只接受同一天內改時段；項目名稱由伺服器讀取；一律建立待批准提案（minor_non_incident），批准時依 SH-04 檢查版本（T34） |
| PWA | `app/manifest.ts`（standalone、圖示 192、512、maskable）；`appleWebApp` 與 apple-touch-icon |

## 安全審查（S-15）

| 檢查 | 結果 |
|---|---|
| 快取範圍 | service worker 不快取 API 與 Server Action；只快取靜態資源、離線頁面與本人可讀的照片 |
| 離線修改 | 只能成為待批准提案；同步端點檢查 Origin、登入、速率限制、角色、項目所屬行程與日期；名稱不採用瀏覽器傳入的文字（多餘欄位整筆拒絕） |
| 版本 | 保留排入時的 base version，批准時依 SH-04 失效，離線修改無法覆蓋他人較新的變更 |
| 照片 | 當日包只保存站內網址 |

沒有發現可被利用的漏洞。
