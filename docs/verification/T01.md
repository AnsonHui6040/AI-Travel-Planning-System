## 安全標頭

| 項目 | 設定 |
|---|---|
| CSP 產生位置 | `apps/web/proxy.ts` 每次頁面請求以 16 bytes 隨機值產生 nonce |
| script-src | `'self' 'nonce-<每次不同>' 'strict-dynamic'`；只有 development 加 `'unsafe-eval'` |
| 其他指令 | `default-src 'self'`、`style-src 'self' 'nonce-…'`、`img-src 'self' blob: data:`、`font-src 'self'`、`connect-src 'self'`、`object-src 'none'`、`base-uri 'self'`、`form-action 'self'`、`frame-ancestors 'none'` |
| HSTS | `max-age=63072000; includeSubDomains`，由 `next.config.ts` 套用到所有路徑 |
| 動態渲染 | 根 layout 呼叫 `connection()`，nonce 只能在請求時套用 |

| 測試 | 內容 | 結果 |
|---|---|---|
| 單元 | script-src 不含 `unsafe-inline`；`frame-ancestors 'none'`；`object-src 'none'`；production 不含 `unsafe-eval`；非 base64 的 nonce 被拒；50 次產生的 nonce 互不相同且至少 128 bit；HSTS max-age 至少一年並含 `includeSubDomains` | 8 個 PASS |
| E2E（390、1280） | 實際回應帶 CSP 與 HSTS；頁面所有 script 的 nonce 等於回應 CSP 中的 nonce；console 沒有 CSP 違規；兩次請求的 nonce 不同 | 4 個 PASS |

日後接入 Supabase、Google 照片等外部來源時，由該 Task 於 `buildContentSecurityPolicy` 加入對應的 `connect-src` 或 `img-src` 並補測試。
