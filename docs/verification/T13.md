## 設計

| 項目 | 說明 |
|---|---|
| SDK | 官方 SDK，版本固定（S-11）：`@anthropic-ai/sdk` 1.6.0、`@google/genai` 3.0.0、`openai` 7.53.0。選擇發布滿兩週的版本 |
| BYOK | 每次呼叫以請求者的 key 建立 client，不共用、不快取 |
| 結構化輸出 | Anthropic：`output_config.format`（json_schema）。Gemini：`responseMimeType` 與 `responseJsonSchema`。OpenAI：Responses API `text.format`（json_schema、strict） |
| schema 轉換 | `toProviderSchema` 只保留各家支援的關鍵字，物件一律 `additionalProperties: false`；長度、數值、數量、pattern 等限制移除，回傳後由角色的 Zod schema 驗證（S-02，T14）。OpenAI strict 要求所有欄位必填，選填欄位改為可為 null，回傳後 `stripInjectedNulls` 移除補上的 null |
| 內建搜尋 | Anthropic `web_search_20260209`（每次最多 5 次搜尋）、Gemini `googleSearch`、OpenAI `web_search`。來源只保留 https 並去重，附取得時間（S-03） |
| Anthropic 搜尋時的 JSON | 搜尋結果一律附引用，而引用不能與 `output_config.format` 並用，所以搜尋時改以系統提示要求最後輸出 JSON，再由最後的文字區塊取出；`pause_turn` 最多續傳 3 次 |
| 工具權限 | adapter 只處理供應商內建搜尋；白名單 fetch 與交通狀態由伺服器執行（T17、T22），送出前即拒絕（S-04） |
| 拒答與截斷 | Anthropic `stop_reason` 不是 `end_turn`、Gemini `finishReason` 不是 `STOP`、OpenAI `status` 不是 `completed` 或含拒答時一律拋出，不回傳內容 |
| 逾時與重試（C-07） | 每次呼叫預設逾時 120 秒；限流與暫時性錯誤以 SDK 內建的指數退避重試 2 次（Gemini 為最多 3 次嘗試）；只連各家官方 HTTPS 端點 |
| 錯誤 | 對外只拋 `ProviderError`：訊息固定，不帶供應商回應、請求內容或 key（C-04）；`classifyError` 對任何輸入都回傳已定義類別 |
| 儲存前測試呼叫（C-03） | 列出模型，不消耗 token；逾時 15 秒、不重試 |
| 認證方式 | 三家都只宣告 `api_key`；OpenAI 的 `plan_oauth` 依 C-06 預留 |
| 註冊 | `defaultProviders()` 以 T11 的註冊表註冊三家 adapter；`defaultKeyTesters()` 提供三個測試呼叫 |

## 錄製回應

`packages/ai/src/testing/fixtures.ts` 依三家官方 API 文件的回應格式建立合成資料，沒有真實 key、帳號或使用者資料：結構化輸出、搜尋（含引用）、拒答、列出模型、各種錯誤。測試以 `fakeFetch` 注入各 SDK 的 `fetch` 選項，不連網路。

## 測試順序

先新增契約測試與 `schema.test.ts`：72 個失敗（RED）。實作後全部通過（GREEN）。實作過程發現 Anthropic SDK 1.x 以 `Authorization: Bearer` 傳送 API key，測試改為接受兩種標頭。

## 安全審查（S-15）

| 檢查 | 結果 |
|---|---|
| key | 只放在當次呼叫的 client；錯誤物件、訊息與 stack 不含 key（契約測試）；client bundle 不含 SDK 與 key |
| 外部連線 | 只連各家官方 HTTPS 端點；有逾時與重試上限 |
| 工具 | adapter 不提供發訊息、寫記憶或改設定的能力；不支援的工具送出前拒絕 |
| 輸出 | 不信任模型輸出：拒答、截斷、不是 JSON 時拋出；內容仍須通過角色的 Zod schema（T14） |
| 來源 | 只保留 https 來源 |
| 依賴 | 三個 SDK 版本固定，發布滿兩週；high 以上漏洞為 0；安裝腳本不執行 |

沒有發現可被利用的漏洞。
