## 設計

| 項目 | 說明 |
|---|---|
| Open-Meteo（D13） | 固定端點 `api.open-meteo.com/v1/forecast`，取逐時氣溫、降雨機率、降雨量、天氣代碼、風速。座標四捨五入到小數第二位（約 1 公里）再送出。欄位長度不一致時拒絕；缺值保留為 null |
| 氣象廳警報 | 2026 年起氣象廳警報頁讀取 `bosai/warning/data/r8/{府県予報区}.json`，舊的 `data/warning/` 停在 2026-05-28，不使用。經白名單 fetch（`www.jma.go.jp` 已在設定檔）讀取。每次發表列出該地區當時全部的警報・注意報，所以各地區以最新一次發表為準，「解除」不列入。代碼表由氣象廳頁面的 `Warning.Common.code2WarningInfo` 取得，含新制的危険警報（レベル４：大雨、高潮、土砂災害）；代碼表沒有的代碼仍列出（名稱、等級為 null） |
| ODPT（D30） | `odpt:TrainInformation`。平常時 `odpt:trainInformationStatus` 省略，視為正常；含「見合わせ」「運休」「不通」為停駛；含「遅延」「遅れ」「乱れ」「運転再開」為延誤；其他文字為其他異常（也轉為 At Risk）。保留原因與預計恢復時間。都營（CC BY 4.0）不需 key；基本ライセンス的資料以使用者本人的 key 呼叫（C-05），沒有 key 時不送出請求 |
| 其他營運商 | Verification 讀取官方運行情報頁後的結果只接受 `officialTransitReport`（`packages/schemas`，多餘欄位拒絕）；來源主機必須在地區 pack 的官方網站白名單；核實時間不可晚於現在、不可超過 30 分鐘，採用後有效 15 分鐘 |
| 有效期限 | ODPT 用 `dct:valid`；沒有提供時自觀測時間起 15 分鐘。逾期資料視為沒有即時資料，不觸發 At Risk |
| HTTP | Open-Meteo 與 ODPT 只連固定的官方端點，不跟隨 redirect，逾時 10 秒，回應上限 2 MB。錯誤訊息只含 HTTP 狀態，不含網址（ODPT 的 key 依規格放在查詢參數） |
| ODPT key 測試呼叫（C-03） | 以東京 Metro（基本ライセンス）的運行資訊做一次查詢 |
| E2E | 五家 key 都有儲存前測試呼叫，E2E 不連外部 API，所以 API key 頁的遮罩與刪除測試改由伺服器函式 `save_api_key` 直接存入 key |

## 安全審查（S-15）

| 檢查 | 結果 |
|---|---|
| SSRF | Open-Meteo、ODPT 的主機固定在程式內，不接受外部網址；ODPT 資料集必須與日本 pack 的清單完全相同（營運商、API 主機、授權）；氣象廳經白名單 fetch，府県予報区與地區代碼以數字格式檢查後才組成網址 |
| key | ODPT key 只放在送往 `api.odpt.org` 的查詢參數；錯誤訊息、測試呼叫的原因、回傳的狀態都不含 key（契約測試斷言）；CC BY 資料集不附 key |
| 不可信資料 | ODPT 與氣象廳的回應逐欄位檢查型別，格式不合的紀錄略過；營運商不符的紀錄略過。官方運行情報頁的核實結果經 strict schema 與來源白名單檢查 |
| 位置 | 送往 Open-Meteo 的座標只到小數第二位 |
| 大小與時間 | 回應上限 2 MB、逾時 10 秒；氣象廳沿用白名單 fetch 的限制 |

沒有發現可被利用的漏洞。
