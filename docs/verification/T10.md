## 設計

| 項目 | 說明 |
|---|---|
| `significanceReasons` | 回傳成立的條件；空陣列即不重大。門檻集中在 `SIGNIFICANCE_THRESHOLDS` |
| `moreReliableSource` | 依第 2.5 節證據順序（`enums.sourceGrade` 的次序）比較兩個來源；同級回傳 null |
| `resolveConflict` | 只決定處理方式：是否產生採用事實的提案、是否標示 At Risk、行程提案為一個或多個、提供給使用者的選項；不寫入任何資料 |
| `USER_CHOICES` | `apply_option`、`ask_ai_rearrange`、`keep_original`，供 T34 等介面 Task 使用 |
| 自動套用 | 只剩新候選、候選核實狀態更新、事實失效標示 At Risk |
