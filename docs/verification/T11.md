## 設計

### 註冊表

| 擴充點 | 註冊表 | 所在套件 | id |
|---|---|---|---|
| AI provider | `createProviderRegistry()` | `packages/ai` | `ProviderAdapter.id` |
| 角色 | `createRoleRegistry()` | `packages/ai` | `RoleSpec.id` |
| 認證方式 | `createCredentialRegistry()`，`available()` 只列可用的方式 | `packages/ai` | `kind` |
| 資料源 | `createDataSourceRegistry()`，`withCapability(能力, 地區)` | `packages/data-sources` | `DataSourceAdapter.id` |
| 地區 | `createRegionRegistry()` | `packages/regions` | ISO 3166-1 兩碼 |

共用的 `createRegistry`（`packages/core/src/registry.ts`）在註冊時執行契約檢查並拒絕重複 id。註冊表不是全域單例，每次建立互相獨立。

### 共用契約（`packages/core/src/extensions.ts`）

| 擴充點 | 契約 |
|---|---|
| `ProviderAdapter` | id 格式；至少一種已知認證方式且不重複；`classifyError` 對任何輸入都回傳已定義類別（逾時、限流、中斷、驗證失敗、其他，對應 T13）之一，不可拋出錯誤 |
| `RoleSpec` | 工具只能取自固定清單（S-04：`provider_search`、`allowlisted_fetch`、`transit_status`，沒有發訊息、寫記憶或改設定的工具）；必須有輸出 schema（與 Zod `safeParse` 相容）；步數 1–100、token 1–1,000,000 的整數（S-06）；資料範圍與記憶範圍只能取自固定清單（MEM-11） |
| `DataSourceAdapter` | 至少一項已知能力（地點、路線、交通狀態、天氣、警報）；地區為 `global` 或兩碼代碼；需 fetch 的主機只能是主機名稱 |
| `RegionPack` | IANA 時區、ISO 4217 幣別、BCP 47 語言；交通狀態與天氣警報來源必須是 https，且主機在官方網站白名單內 |
| `CredentialProvider` | `api_key` 或 `plan_oauth`；`plan_oauth` 第一版以 `available: false` 註冊 |

### 記憶範圍（MEM-11）

| 項目 | 說明 |
|---|---|
| 介面 | `MemoryReader.read({ ownerIds, tripId, scope })`，取代原本的 `listForOwner` |
| 過濾 | core 的 `scopeMemories` 只保留角色 `memoryScope` 內的層級與類型；範圍為空時不送出記憶 |
| 預設實作 | `packages/memory` 的 `emptyMemoryReader` 回傳空記憶 |
| Supabase 實作 | 查詢以 `in` 限制擁有者、層級、類型，回傳前再經 `scopeMemories` 過濾；範圍為空時不查詢資料庫 |

## 安全審查（S-15）

| 檢查 | 結果 |
|---|---|
| 角色工具 | 工具清單封閉，註冊時拒絕清單以外的工具（S-04） |
| 角色上限 | 步數與 token 上限必須是有上限的正整數（S-06） |
| 記憶 | 資料庫查詢與回傳前都依角色記憶範圍過濾（MEM-11）；範圍為空時不查詢 |
| 憑證 | `Credential` 只在伺服器內傳遞；`CredentialProvider.resolve` 只取請求者本人的憑證（D15）；`plan_oauth` 預設不可用 |
| 地區來源 | 來源必須是 https，主機必須在白名單內，避免把非官方網址當作官方情報 |
| feature flag | RLS 啟用；只授權 authenticated 讀取，收回 anon 與 authenticated 的寫入權限；讀取失敗時拋出錯誤 |
| core 依賴 | `registry.ts`、`extensions.ts` 只 import `@atps/schemas`，只使用 JavaScript 內建的 `Intl` 與 `URL`（M-01） |

沒有發現可被利用的漏洞。
