# 0003 行程、每日狀態的轉換時點

| 項目 | 內容 |
|---|---|
| 狀態 | 已決定 |
| 日期 | 2026-11-23 |
| 決定者 | 使用者 |
| 相關 | 計畫第 2.8 節、第 11 節、T07 |

時間一律以行程的目的地時區計算。

## 行程

| 轉換 | 時點 |
|---|---|
| 基線 → 規劃中 | 使用者確認 Trip Baseline v1 |
| 規劃中 → 已鎖定 | 所有日期均為已批准（至少一日） |
| 已鎖定 → 規劃中 | 任一日改回草案 |
| 已鎖定 → 進行中 | 第一日 00:00 自動開始 |
| 進行中 → 已結束 | 最後一日的 Actual Timeline 產生後；或最後一日結束後 24 小時自動進入 |
| 已結束 → 已封存 | 所有項目都已標示旅後狀態 |

## 每日

| 轉換 | 時點 |
|---|---|
| 草案 → 已批准 | 使用者批准該日 |
| 已批准 → 草案 | 使用者改回草案 |
| 已批准 → Day Ready | Morning Check 通過，且該日已為已批准 |
| 已批准或 Day Ready → 進行中 | 第一個活動的排定開始時間，或成員記錄第一個活動完成時，取較早者 |
| 進行中 → 已完成 | 當日 Actual Timeline 產生後 |
