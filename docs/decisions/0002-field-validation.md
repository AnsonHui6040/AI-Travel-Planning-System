# 0002 AI 填寫欄位的驗證格式與上下限

| 項目 | 內容 |
|---|---|
| 狀態 | 已決定 |
| 日期 | 2026-11-23 |
| 決定者 | 使用者 |
| 相關 | 計畫第 2.4 節、第 11 節、S-02、T06 |

超出範圍或格式不符的 AI 輸出整筆丟棄並記錄（S-02）。Zod schema 與資料庫 check constraint 使用相同數值。

| 欄位 | 規則 |
|---|---|
| 中文名稱 | 1–80 字 |
| 當地名稱 | 1–120 字 |
| 地址 | ≤200 字 |
| 推薦原因、限制說明 | 各 ≤300 字 |
| 建議停留時間 | 5–600 分鐘 |
| 日期 | ISO 8601（YYYY-MM-DD） |
| 時間 | HH:mm（00:00–23:59） |
| 時區 | IANA 名稱 |
| 優先級 | 1–5 |
| 八個篩選維度 | 各 0–5 整數 |
| 來源網址 | 只限 https，≤2048 字元 |
| 取得時間 | ISO 8601 日期時間，必須含時區 |
| 金額 | 0–10,000,000；幣別為 ISO 4217 三個大寫字母 |
| 交通估算 | 門到門 1–1440 分鐘；步行 0–600 分鐘；轉乘 0–10 次 |
| 固定選項 | 類型、限制類別、天氣依賴度（低、中、高）、預約要求（不需要、建議、必須）、來源等級（依證據順序四級） |
