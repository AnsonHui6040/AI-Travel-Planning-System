# 0007 候選篩選以確定性規則評分

| 項目 | 內容 |
|---|---|
| 狀態 | 暫定（使用者可改為 AI 評分） |
| 日期 | 2026-11-24 |
| 決定者 | Claude（依使用者「用量 95% 前不必詢問」的指示先行決定，待使用者確認） |
| 相關 | 計畫第 2.4 節、T26、T27、T28 |

## 背景

T26 要為每個候選評八個篩選維度並標記 Primary 或 Backup，計畫沒有指定由 AI 或規則評分。

## 比較

| 面向 | 確定性規則（採用） | AI 評分 |
|---|---|---|
| 費用 | 不呼叫 AI | 每次研究多一次 AI 呼叫 |
| 可測試 | 每個規則有單元測試，結果可重現 | 需錄製回應與真 AI 評估 |
| 判斷深度 | 只用基線、地區、類型、停留時間與已知事實 | 可考慮評價、氛圍等文字資訊 |

## 規則（0–5，5 = 最適合排入）

| 維度 | 規則 |
|---|---|
| 個人價值 | 預設 3；攝影類且基線有攝影需求 4；必去地點 5；排除地點 0 |
| 獨特性 | 預設 3；Research D（冷門替代）4；同地區同類型有 3 個以上時最高 2 |
| 地理配合 | 在住宿或固定活動的地區 5；同地區有 3 個以上候選 4；其他 2；沒有地區 1 |
| 時間成本 | 停留 60 分鐘以內 5、120 以內 4、180 以內 3、240 以內 2、超過 1 |
| 交通成本 | 在住宿或固定活動的地區 5；其他 3；沒有地區 2。T28 取得交通估算後改以估算計算 |
| 天氣依賴 | 攝影 1、景點與活動 3、餐飲與購物 5（同時設定天氣依賴度高、中、低） |
| 時段依賴 | 預設 4；有營業時間或休館日 3；需要預約或攝影類 2 |
| 替代性 | 同地區同類型沒有其他候選 5、1 個 3、2 個以上 1；必去地點 5 |

## Primary 與 Backup

每個地區與類型的組合中，總分最高的 2 個為 Primary，其餘為 Backup（同分依名稱排序）。必去地點一律 Primary，排除地點一律 Backup。優先度為總分除以 8 四捨五入（1–5）。
