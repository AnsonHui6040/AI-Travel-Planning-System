# 0004 延誤分級與 L1 最低緩衝

| 項目 | 內容 |
|---|---|
| 狀態 | 已決定 |
| 日期 | 2026-11-23 |
| 決定者 | 使用者 |
| 相關 | 計畫第 2.6 節、第 11 節、T08 |

| 延誤 | 分級 | 處理 |
|---|---|---|
| 0–9 分鐘 | 不視為 Incident | 只更新預計到達時間 |
| 10–20 分鐘 | L1 | 產生壓縮緩衝提案並通知，需確認（決策 0005） |
| 21–60 分鐘 | L2 | 需批准 |
| 超過 60 分鐘 | L3 | 需批准 |
| 使下一個 Hard Constraint 無法準時（不論分鐘數） | L3 | 需批准 |

L1 壓縮後，距下一個 Hard Constraint 的緩衝少於 15 分鐘，自動升為 L2。
